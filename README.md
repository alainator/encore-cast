# Encore's Google Cast receiver

The page a Chromecast, Google TV or TV with Cast built in loads when an Encore station casts to it. The station sends
its party's TV page address (on the local network), and the Cast device goes there. Only an Encore TV page (`/tv`) on
a private network address is accepted.

Served by GitHub Pages at `https://alainator.github.io/encore-cast/receiver.html` (the Custom Receiver URL of the Cast
app). The copy in the Encore repo (`cast/receiver.html`) is the one to edit.
